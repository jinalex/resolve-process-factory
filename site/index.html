Find the gaps in your SOP. Then apply it the same way to every case.

Resolve turns a written procedure (an SOP) into rules and checks them with a solver for contradictions and gaps. The procedure's owner settles each one with a plain answer. Then the approved rules decide every case, and say exactly which facts are still missing. A fact nobody has established is unknown, never a no.

This prototype runs on a Know Your Business (KYB) procedure: the checks a bank runs to confirm who owns and controls a company before opening its account.

Install the mod

Resolve is meant to be used as a pane beside the chat in Claude Code: the spec's open questions for the owner, every case's outcome and case file, and approving a version. In Claude Code:

/plugin install resolve --marketplace jinalex/resolve-process-factory
/resolve

The repository is private for now, so installing needs read access to it. Ask the maintainer. From a checkout you can also load it directly with claude --plugin-dir mod/resolve. Then run pnpm resolve at the repo root to write the files the pane reads.

Run it from a checkout

Needs Node 22.23.4 or later and pnpm. Commands that call Claude need RESOLVE_ANTHROPIC_API_KEY; the rest run offline.

git clone https://github.com/jinalex/resolve-process-factory
cd resolve-process-factory && pnpm install
pnpm test            # outcomes, Z3's checks, Z3 agreeing with the evaluator
pnpm examples        # each example case's outcome and why
pnpm check-sop       # Z3's findings on the KYB SOP
pnpm resolve         # write .resolve/ for the pane
pnpm write-options   # Claude writes the owner's questions (needs the key)
pnpm next-spec       # the owner's answers become the next spec version
pnpm build-site      # this page, into site/dist/
